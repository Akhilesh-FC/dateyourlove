# Plesk deployment steps

1. Create a Node.js app in Plesk.
2. Point the document root to the project folder.
3. Set the startup file to:
   - server.js
4. In Plesk Environment Variables, add:
   - PORT=3000
   - NODE_ENV=production
   - DB_HOST=...
   - DB_USER=...
   - DB_PASSWORD=...
   - DB_NAME=...
   - API_TOKEN=...
   - API_MERCHANT_KEY=...
   - JWT_SECRET=...
5. Install dependencies in Plesk using npm install.
6. Start the app from Plesk.

Note:
- For production, keep secrets in Plesk environment variables instead of .env files.
- If your app uses MySQL, make sure the database is reachable from the Plesk server.
